# android-moja-wizytowka

## Cel projektu
Celem projektu jest poznanie podstaw języka Kotlin,
nauka tworzenia aplikacji Android oraz wykonanie
własnej wizytówki z wykorzystaniem Jetpack Compose.

## Realizacja projektu
Projekt realizowany jest na podstawie kursu:
Android Basics with Compose – Unit 1.
